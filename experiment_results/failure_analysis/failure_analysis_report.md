### 3.1 AMCL粒子枯竭，定位丢失（Kidnapped Robot Problem）

**根因分析:**
```
AMCL 粒子滤波的理论局限性:
  1. 粒子枯竭（Particle Depletion）: 重采样过程中低权重粒子被丢弃，导致粒子多样性丧失。
  2. 全局重定位困难: 标准 AMCL 依赖运动模型传播粒子，被搬运后无法恢复。
  3. 感知混淆: 对称环境（如走廊）导致多模态后验，粒子可能集中在错误区域。
  4. 样本贫化: 有效粒子数 ESS = 1 / Σ w_i² 过低时，估计不可靠。

实际观察到的根因（1 个案例）:
AMCL 粒子滤波发生粒子枯竭（Particle Depletion）。可能原因: (1) 机器人被搬运到新位置（kidnapped）; (2) 感知混淆导致粒子集中在错误区域; (3) 有效粒子数不足，无法表达多模态后验。根本原因: 标准粒子滤波在全局重定位场景下缺乏恢复机制。
```

- 严重程度: 0.94
- 定位误差: 1.500
- 覆盖率: 0.0%

**改进建议:**
```
改进建议: (1) 启用 KLD-Sampling 自适应粒子数（已有实现）; (2) 添加随机粒子注入机制（每步注入 5% 随机粒子）; (3) 检测到 loc_err 突变时触发全局重定位; (4) 融合 IMU 里程计减少运动模型不确定性; (5) 使用 MCL+MHT（多假设跟踪）处理多模态后验。
```

### 3.2 狭窄通道卡死，机器人无法通过

**根因分析:**
```
狭窄通道规划的理论局限性:
  1. 代价地图膨胀: inflation_layer 对所有障碍物统一膨胀，窄通道可能被完全占据。
  2. 局部最优陷阱: DWA/TEB 在窄通道入口处容易振荡，无法找到可行速度。
  3. 运动学约束: 四足机器人的转弯半径限制，在窄通道中无法执行大角度转向。
  4. 全局-局部不一致: 全局路径假设可通过，但局部规划器发现实际不可行。

实际观察到的根因（1 个案例）:
狭窄通道卡死。可能原因: (1) 代价地图膨胀半径过大，通道被完全占据; (2) 局部规划器（DWA/TEB）在窄通道中振荡，无法生成有效轨迹; (3) 全局路径穿过实际不可通行的区域; (4) 机器人尺寸大于通道有效宽度。根本原因: 规划器对狭窄通道的通过能力估计过于乐观。
```

### 3.3 动态障碍物碰撞，避障失败

**根因分析:**
```
动态避障的理论局限性:
  1. 预测不确定性: 线性外推假设匀速运动，无法捕捉加减速、转向。
  2. 时滞问题: 规划周期（0.2-0.5s）内的障碍物运动无法预测。
  3. 多障碍物交互: 多个动态障碍物的交互行为难以建模。
  4. 安全距离权衡: 安全距离过大导致频繁停止，过小导致碰撞。

实际观察到的根因（1 个案例）:
动态障碍物碰撞。可能原因: (1) 轨迹预测不准确，使用线性外推无法捕捉非线性运动; (2) 规划周期过长（>0.5s），无法及时响应快速移动的障碍物; (3) 动态障碍物安全距离不足; (4) CBF 安全过滤未启用或参数过于保守导致过滤失效; (5) 代价地图中动态障碍物的清除速度过快，导致历史轨迹残留。根本原因: 动态环境的时变特性超出了反应式避障的响应能力。
```

### 6.8.3 方法局限性总结

基于失败案例分析，本文方法存在以下局限性：

1. **定位鲁棒性局限**: AMCL 在全局重定位场景下容易发生粒子枯竭，恢复时间不可预测。本文的 KLD-Sampling 改进缓解但不完全解决此问题。

2. **狭窄通道通过能力**: 代价地图膨胀机制在保证安全性的同时限制了窄通道通过能力，本文未实现自适应膨胀半径。

3. **动态环境响应延迟**: 当前规划周期（0.2s）对高速障碍物（>1m/s）响应不足，GNN 预测部分缓解但未完全消除时滞。

4. **探索完备性**: 贪心探索策略无法保证100% 覆盖率，死区问题在复杂环境中仍然存在。信息增益策略改善了但未完全解决此问题。

5. **计算复杂度**: AUFE 自适应权重的在线计算增加了约 15% 的计算开销，在嵌入式平台上可能影响实时性。

6. **假设条件**: 本文方法基于以下假设，超出假设范围时性能下降：
   - 环境静态结构不变（动态变化由动态避障处理）
   - 传感器模型准确（无系统性偏差）
   - 机器人运动学模型已知（无打滑）
   - 计算资源充足（实时性可保证）
